# 🛒 Retail Sales Analysis Dashboard

## 📌 Overview
This project focuses on analyzing retail sales data to understand revenue trends, product performance, and regional distribution.

## 🛠️ Tools Used
- Power BI  
- Python (Jupyter Notebook)  
- Pandas  

## 📊 Key Insights
- Identified top-selling products  
- Analyzed sales trends over time  
- Evaluated regional performance  
- Studied the impact of discounts on sales
